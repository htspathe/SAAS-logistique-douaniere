# Direction artistique

## Positionnement visuel

TransitFlow SN doit inspirer la maîtrise opérationnelle, la confiance et la modernité. L'identité s'appuie sur l'univers portuaire sénégalais sans reprendre un modèle existant.

## Palette initiale

| Usage | Couleur |
| --- | --- |
| Bleu principal | `#09223E` |
| Bleu très sombre | `#071827` |
| Turquoise action | `#0CA898` |
| Jaune signal | `#E9C63F` |
| Blanc cassé | `#F7F5EF` |
| Gris de bordure | `#D9D6CC` |

Le turquoise représente le suivi et les actions confirmées. Le jaune attire l'attention sur les appels à l'action et les points importants. Le rouge reste réservé aux erreurs ou alertes critiques.

## Deux interfaces complémentaires

- Le site public présente le problème, la solution, le suivi maritime, la sécurité et les publics visés.
- Le tableau de bord privilégie la densité d'information, la lisibilité et la rapidité d'exécution.
- Les deux partagent le logo, les couleurs, la typographie et les composants principaux.

## Principes

- identité originale ;
- priorité au mobile et aux connexions moyennes ;
- chiffres commerciaux réels uniquement ;
- toute donnée maritime simulée doit être identifiée comme telle ;
- contrastes suffisants et libellés compréhensibles ;
- aucune image ou maquette tierce copiée dans le produit.

## À NOTER

### Exclusions définies avec le porteur du projet

1. Dégradés violet-bleu.
2. Titres en dégradé.
3. Emoji décoratifs.
4. Police Inter appliquée partout par défaut.
5. Bordures colorées systématiques.
6. Effets de verre translucide (glassmorphism).
7. Interfaces sombres illisibles.
8. Trois blocs génériques à icônes.
9. Badge décoratif dans le hero.
10. Icônes Lucide omniprésentes.
11. Composants shadcn sans adaptation.
12. Apparitions progressives systématiques.
13. Traînées suivant le curseur.
14. Boutons qui s'estompent au survol.
15. Espacements incohérents.
16. Tirets cadratins excessifs.
17. Vocabulaire commercial creux.
18. Accents typographiques en serif italique.
19. Association Space Grotesk et Instrument Serif.
20. Grain superposé à un dégradé.

Appliquer une échelle d'espacement cohérente, conserver les états de formulaire accessibles et vérifier les contrastes. Les boutons principaux à texte blanc utilisent un turquoise foncé (`teal-800`) dans les nouveaux écrans métier.

Le nom « TransitFlow SN » et le logo à base d'ancre sont provisoires. Ils devront être validés avant l'enregistrement du domaine et le lancement commercial.
