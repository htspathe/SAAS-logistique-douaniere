# Feuille de route

## Phase 1 — Fondations

- authentification et gestion des organisations ;
- tableau de bord ;
- création et suivi des expéditions ;
- historique des statuts.

## Phase 2 — Documents

- dépôt sécurisé de documents ;
- catégories documentaires ;
- validation et demandes de pièces manquantes ;
- journal d'audit.

## Phase 3 — Portail et notifications

- portail client ;
- notifications par e-mail ;
- intégration WhatsApp ;
- rappels automatiques.

## Phase 4 — Industrialisation

- tests automatisés ;
- SonarQube et Trivy ;
- observabilité ;
- conteneurisation et déploiement cloud ;
- infrastructure as code.
